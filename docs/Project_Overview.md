# Project Overview

## Objective

The objective of this project is to design and implement a dimensional data warehouse for Clinical Trial Site Enrollment analytics using a Star Schema.

The project demonstrates how transactional healthcare data can be transformed into an analytical model suitable for reporting and business intelligence.

---

## Business Scenario

Clinical trial organizations manage multiple studies across several research sites.

Every day:

- New patients enroll.
- Existing patients complete studies.
- Sites recruit participants.
- Sponsors monitor study progress.

Although this information exists in operational systems, it is difficult to generate analytical reports directly from normalized databases.

To solve this problem, a dimensional data warehouse is created.

---

## Goals

- Build a Star Schema
- Design Fact and Dimension tables
- Load sample data
- Execute analytical SQL queries
- Demonstrate dimensional modeling principles
